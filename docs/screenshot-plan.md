# Screenshot Plan

Capture screenshots only from a disposable WordPress site with fake or redacted
provider data.

Suggested private package screenshots:

- PressQueue settings with dry-run and kill switch visible.
- Connections list with no credential values displayed.
- Channels list with disabled-by-default destinations.
- Rules list and rule editor with the condition builder.
- Post editor controls and nondurable preview.
- Delivery list and delivery detail with redacted diagnostics.
- Batch preview and confirmation screen.
- Privacy screen showing runtime state, export, retention, and uninstall
  controls.

Store raw screenshots in scratch evidence. Keep durable QA evidence to a short
summary that names the screenshot set, date, runtime, and any visible
limitations.
