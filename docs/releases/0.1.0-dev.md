# PressQueue 0.1.0-dev

This is a private development package note. It is not a public release note
and does not approve publication, WordPress.org submission, repository
visibility changes, or live provider delivery.

## Scope

- Guarded plugin bootstrap with PHP, WordPress, and network activation checks.
- Local storage schema, role capabilities, rules, templates, editor controls,
  previews, batches, delivery records, queue sweep, and worker handoff.
- Buffer API-key connection, channel discovery, and delivery adapter code
  behind fakeable transports.
- Privacy settings, administrator JSON export, WordPress personal data
  exporter and eraser callbacks, disabled-by-default retention, and
  preserve-by-default uninstall behavior.
- Private package smoke and local matrix tooling for disposable validation.

## Privacy And Security

- Provider credentials are stored locally through encrypted envelopes and are
  excluded from exports.
- Rendered social text and media URLs are excluded from exports by default and
  require exact administrator confirmation for inclusion.
- Retention is disabled by default, lease-based when enabled, and limited to
  resolved local records that meet the retention window.
- Uninstall preserves data by default. PressQueue role capabilities are removed
  on uninstall whether or not data deletion is enabled.

## Validation Expectations

Before treating a private package as a release candidate, run the unit suite,
PHPCS, PHPStan, Composer validation and audit, runtime smoke checks, package
smoke in a disposable WordPress install, Plugin Check, and the supported local
matrix where Docker is available.

## Known Limits

OAuth, public distribution, standing evergreen automation, and live provider
proof are intentionally outside this development package.
