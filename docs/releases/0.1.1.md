# PressQueue 0.1.1

This update addresses the technical findings from the WordPress.org directory
review. It keeps the same sharing rules, saved data, and delivery behavior.

Admin header HTML is sanitized before output. Font URLs in social-image settings
are escaped, and CLI responses use WordPress's JSON encoder.
Empty-state action links are sanitized too. The quick-start rule form keeps
its nonce and submit button.
Generated admin HTML is escaped at output throughout the screens. Icons and
responsive thumbnails keep the attributes they need.

The bundled Action Scheduler is updated to 4.2.0. **WordPress 6.9 or newer is now
required.** Update WordPress before installing this version on an older site.
PHP 8.1 or newer is still required.

The Channels screen links to WordPress's security-key documentation. PressQueue
does not call a remote salt generator or send site keys to WordPress.org.
