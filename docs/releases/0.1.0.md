# PressQueue 0.1.0

PressQueue 0.1.0 is the first public release. PressQueue is a free WordPress
plugin for Buffer. When you publish a post, it adds the post to your Buffer
queue with the message and image your rules set, and Buffer posts it on
LinkedIn, X, Bluesky, Mastodon, Threads and Facebook.

Connect Buffer with an API key, switch on your channels and create a rule.
PressQueue starts in test mode, so you can see what it would share before
anything goes out. When the test runs look right, go live.

In this release:

- Social images drawn from the post title, which can also be the link preview
  of your posts.
- Rules that pick posts, channels, message, timing and image with ordinary
  form fields.
- "Never share" rules and a "Share this post" switch in the block and classic
  editors.
- Share now in the editor for a published post that was never shared.
- Sharing older posts in batches you review first.
- An Activity page that explains every share in plain words.
- Test mode, Live and Paused as one switch.

Requirements: WordPress 6.8 or newer, PHP 8.1 or newer and a Buffer account.
Buffer's free plan works.

Install: download `pressqueue.zip` below (not GitHub's "Source code" file) and
upload it under Plugins > Add Plugin > Upload Plugin.

Documentation: https://www.pressqueue.com/docs/
