# PressQueue 0.1.0

The first public release of PressQueue, a WordPress plugin that shares your
posts on social media through Buffer.

Connect Buffer with an API key, switch on your channels and create a rule.
PressQueue starts in test mode, so you can see what it would share before
anything goes out. When the test runs look right, go live.

Highlights:

- Rules that pick posts, channels, message, timing and image with normal controls.
- "Never share" rules and a "Share this post" switch in the editor.
- A reviewed flow for sharing older posts.
- An Activity page that explains every share in plain words.
- Test mode, Live and Paused as one switch.

Requirements: WordPress 6.8 or newer, PHP 8.1 or newer and a Buffer account.
