# PressQueue 0.1.0

This is the first release candidate. It remains local and private until the
owner approves publication.

PressQueue sends WordPress posts to Buffer using rules. You can preview messages,
choose destinations, save unscheduled drafts, and review each delivery attempt.
Manual batches handle older posts and deliberate reposts.

Dry-run mode starts enabled. Rules, connections, and channels start disabled.
Delivery rechecks current exclusions and whether the post is still public.
An uncertain provider response needs review before another attempt.

See [Getting started](../getting-started.md) for setup and
[Privacy and data](../privacy.md) for stored data and remote requests.
