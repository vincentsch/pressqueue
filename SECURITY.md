# Security reports

Report a security issue privately through the repository's **Security > Report
a vulnerability** option when it is available. If it is not, ask the maintainer
for a private way to report it, without posting exploit details.

Include the affected version, the steps to reproduce the issue and its impact.
Leave API keys, WordPress salts, account details and private content out of
the report. Do not test against someone else's WordPress site or social
account.

Security fixes go into the latest release. PressQueue is young, so please
update to the newest version before you report.
