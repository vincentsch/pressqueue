# Security reports

Report a security issue privately through the repository's **Security > Report
a vulnerability** option when it is available. If it is unavailable, ask the
maintainer for a private reporting route without posting exploit details.

Include the affected version, the steps needed to reproduce the issue, and its
impact. Remove API keys, WordPress salts, account details, and private content
from your report. Do not test against someone else's WordPress or social account.

Security fixes go into the latest release. PressQueue is young, so please
update to the newest version before reporting.
