# Security reports

Report a security issue privately through **Security > Report a
vulnerability** on the GitHub repository. If that does not work for you,
email hello@pressqueue.com and leave the exploit details out of the first
message.

Include the affected version, the steps to reproduce the issue and its impact.
Leave API keys, WordPress salts, account details and private content out of
the report. Do not test against someone else's WordPress site or social
account.

Security fixes go into the latest release. Check that the problem is still
there in the newest version before you report it.
