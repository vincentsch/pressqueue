# PressQueue

PressQueue is an open-source WordPress plugin that shares posts to social networks
through Buffer, based on rules the site owner sets.

The documentation lives in the files below. Good places to start:

- `CONTRIBUTING.md`: local development, code layout and the rules every change keeps
- `README.md`: what the plugin does, setup and the checks to run
- `docs/developer/`: provider extensions, WP-CLI and observation hooks
- `SECURITY.md`: how to report a security issue

This file is only a signpost, not a full guide. Please add new notes,
decisions and rules to the docs above rather than here.
